## Context

The source of this site: CTF writeups, security notes and projects. Static output, no backend, no database, no accounts.

## Stack

- Astro in static mode, content written in MDX with Zod-validated collections.
- Tailwind CSS, Shiki for code highlighting.
- Pagefind for search, built after the Astro build.
- Social images generated with satori and resvg.
- Reproducible build with a Nix flake.
