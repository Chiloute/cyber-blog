## Context

Spilltea is a terminal-native HTTP(S) interception proxy written by [anotherhadi](https://github.com/anotherhadi). It sits between the browser and the internet to inspect, modify and replay traffic without leaving the terminal. I contribute to the project.

## Features

- Keyboard-driven interception, editing and replay of HTTP(S) requests.
- Per-project configuration.
- Plugin system in Lua.
- Vim / Neovim integration.
